# Catalog v0.5 Excel 导入基础设计

状态：设计与模板交付。本版不提供文件上传、导入写入端点或后台导入任务。

## 文件与列

使用 templates/products.csv 作为可由 Excel 打开的 UTF-8 示例。导入 Excel 时将编码、条码、规格、单位编码和金额列设为文本，防止前导零丢失或科学计数法转换。后续正式上传格式为 xlsx；禁用宏与公式执行，拒绝加密文件，初始限制 10 MB / 10,000 行。逐行保留原始字符串、文件名和源行号，清洗值另存。

商品列：商品编码、条码、商品名称、简称、分类编码、品牌编码、型号、规格、基础单位编码、最低库存数量、建议补货数量、首选供应商编码、备注，以及 `属性:<分类模板属性键>`。价格与换算使用单独工作表，不从商品表建立第二份价格事实源。首版每份预览只处理一种资源；依赖顺序为分类/品牌/单位/客户/供应商 → 商品 → 单位换算 → 价格/供货关系。

## 清洗与解析

只做可解释的清洗：去除首尾空白、识别全角空格、统一显示用乘号。原始 SKU 和条码不做大小写改写；当前编码区分大小写，疑似近似编码提示人工确认。名称不自动合并。不会猜测 `箱=1000个`，换算率必须明确输入并转换为 Decimal，精度上限与 API 一致。空字符串不变成零单价；价格缺失是未设置。

分类、单位、品牌、客户和供应商通过当前组织中的编码解析为 ID。禁止从文件接受 organization_id、用户 ID、状态、版本、search_text 等系统字段。属性按分类模板校验未知键、必填、枚举、数值和布尔类型。禁止 Excel 公式；导出预览时以 `= + - @` 等起始的文本按文本单元格输出，防止公式注入。

## 预览、重复与提交

预览显示行号、原值、清洗值、拟执行动作、错误代码和中文原因。错误码包括 REQUIRED、UNKNOWN_REFERENCE、INVALID_ATTRIBUTE、INVALID_DECIMAL、DUPLICATE_IN_FILE、EXISTING_CODE、VERSION_CONFLICT。文件内相同 SKU、条码、供应商货号或重复价格键均为冲突，不采用最后一行覆盖。

现有编码默认不覆盖。用户显式选择更新时，预览记录 expected_version；提交重新检查权限、引用状态、分类模板版本与资源版本。预览不得锁住数据库或视为授权。存在错误时不提供提交操作。

未来确认导入必须调用与 UI 相同的 application commands；每行用 import_id + row_id + action 构成幂等键，写入、审计、Outbox 同事务。采用逐行事务并明确展示已成功、失败和未执行行，重试只重试失败行；不会声称整个文件原子成功。导入日志按组织隔离并受专门权限控制，文件保留期与审计保留期须在实现导入前决定。

## 后续实现的验收案例

前导零条码；Excel 科学计数法误改提示；中文/乘号与空格；未知分类；跨租户编码；同文件重复；负数/浮点/超精度价格；未知属性与枚举；预览后并发修改；中途失败重试；重复确认；公式注入；超限文件与权限撤回。
