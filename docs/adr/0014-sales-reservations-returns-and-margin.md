# ADR 0014 — 销售占用、退货成本与毛利

Status: Accepted for incremental implementation after user continuation。S1–S3后端已实施，工作台和完整验收在S4–S5落实；基线为已发布main64bec0a / purchasing-v0.7。依据权威迁移上下文4.3、5、7–10、12、41及ADR0009/0012/0013。详见[施工规范](../sales-v0.8.md)和[验收清单](../sales-v0.8-acceptance.md)。

## 原文已经固定

确认销售订单增加占用而不减少现有量，出库消费占用并减少现有量；禁止负库存；移动加权平均成本；历史单位快照；业务/履约/结算状态分开；不可变事实、显式Command、同事务Audit/Outbox/幂等及RLS。下列选择补足原文没有细化的边界。

| 决策 | 本阶段建议 | 理由 / 替代方案的代价 |
|---|---|---|
| S1 订单范围与释放 | 单客户单仓、每商品一行；确认全量占用，缺货整单拒绝；取消无有效出库订单、关闭剩余均释放占用；不自动关闭/重开 | 沿用已有库存不变量。欠货或部分确认需要另一套承诺量和状态，不默认引入 |
| S2 履约与退货 | 有效出库计履约，退货单列、不重开待发/占用；补发另开订单 | 区分“发出了多少”和“后来退回多少”。自动补发需新需求确认，不把退货直接当补发指令 |
| S3 退货成本 | 按原销售出库实际成本按原数量比例回收，准确金额入库；当前移动均价正常重算 | 使原销售的净成本和净毛利可核对。按退货当前均价会引入额外计价差异，不默认把其混入销售毛利 |
| S4 冲销与关闭 | 仍为严格末笔整单；出库冲销要求订单CONFIRMED且无有效退货，恢复原占用；CLOSED后拒绝出库冲销；退货及合法退货冲销仍允许 | 避免闭单恢复悬空占用。若要求闭单后冲销出库，需要另定义恢复占用后释放或重开语义，不能静默实现 |
| S5 价格来源 | 专属→最近有效出库成交→客户等级→标准；目录价仍是基本单位价，历史价按原因子转换；保存草稿定价，确认不暗中重报 | 沿用原优先级并保留来源。历史全退成交仍是成交，除非原出库被冲销；若要排除全退价格须明确另立规则 |
| S6 成本权限 | 销售开单/确认需交易价格权限，出入库仓管可以只看数量；成本和毛利另受product.cost.read与价格权限共同控制 | 不为了让销售员出库而授予进价/毛利。低价或负毛利如实记录，不擅自加审批 |
| S7 占用来源接入 | 内部SALES_RESERVATION凭据，独立SALES_SHIPMENT/SALES_RETURN；库存行新增受租户FK保护的reservation_source_line_id，由Command写入；引擎核对跨凭据消费 | 当前引擎只接受同一来源行消费，占用订单行与出库行必须显式关联；不能复用行ID伪造来源或删掉原校验 |
| S8 数值和资金 | 数量/单价6位、金额4位，Decimal精度50；退完时分别清掉销售金额和原成本尾差；200行/100条页上限；不生成应收/收款/退款 | 金额差异和现金不是一回事。资金、税费、折扣、关账期和历史财务报表后续独立规范 |

## 数值示例与纠错含义

库存200、均价11，确认100后现有200/占用100。卖60×15，现有140/占用40，销售900、成本660、毛利240。原单退10，入库价值110、销售冲减150；现有150/占用40，净销售750、净成本550、净毛利200。未发仍40；关闭后占用释放到0。

退货不是冲销：库存已经继续流转时可以按原出库来源退货，但退货入库按当前库存重新算均价。出库冲销仍必须无后续流水，精确恢复原状态。后续退货即使冲销也留下事实，因此更早出库不会自动恢复末笔资格。

## 实施前应复核

重点复核S1全量占用、S2退货不补发、S3原出库成本回收、S4闭单后不冲销出库、S5全退历史价保留以及S6仓管无成本仍可过账。这些是明确建议，不是原文已经逐字定义的规定；变化时同步改规范、迁移约束与验收样例。

本阶段没有发现需要推翻原文的真正冲突。引擎同来源消费限制是现有接口尚未覆盖销售流程，需受控扩展；ProductPrice基础单位语义是既有契约，不能改成销售包装价；function scope事务提交修复必须保留。

## S1落地

占用凭据使用sales_documents的内部RESERVATION种类和sales_document_lines映射，库存凭据行与订单行ID独立，不伪造实物出库来源。0009_sales建立四张租户表、不可变来源和权限；跨凭据消费字段延至S2的新迁移。报价商品读取权限沿用catalog.read。有效成交历史解析已用隔离查询fixture验证；尚未实现销售出库Command，不能据此认定出库业务通过验收。


## S2落地

0010_sales_shipments追加reservation_source_line_id和租户复合自引用外键；引擎sales.ship能力仅允许DRAFT销售出库的ISSUE，必须提供与冻结来源匹配的reservation，不能消费别单或绕过占用。同一INVOCER权限的只读SQL谓词服务于延迟约束和立即引擎校验，不授予新的业务写权限。

出库实际成本从不可变流水读取；订单行与出库商业行保持不可变。当前不开放销售冲销，避免在S3前形成不完整逆向状态。详情共享锁和列表重新筛选属于读取一致性修复，不改变业务语义。


## S3 落地

0011_sales_returns 追加原出库行租户外键和准确退货成本快照。销售冲减与原成本回收各自分配尾差；草稿保存和过账都校验剩余可退量，过账发现已保存分配变化时要求显式刷新草稿。库存引擎核对实际原流水与准确成本，保留原事实。

销售出库冲销恢复原占用，退货冲销只恢复可退额度；严格末笔、闭单规则不变。当前成本查询从不可变流水取得，订单净毛利只纳入有效 POSTED 事实；退货单毛利表示带符号的净影响，DRAFT/REVERSED 不计已实现毛利。成交历史保留全部退回但未冲销的出库。

销售金额汇总只需销售与价格读取权限；成本和毛利另需成本读取权限。数量操作回执不包含商业值。S4 页面须延续这些边界，明确展示退货的销售冲减和成本回收。
