# ADR 0018：网页模型服务配置与密钥边界

状态：已实施，供架构复核。日期：2026-09-06。

用户明确要求在网页自由设置 LLM 供应商，取代固定供应商和终端密钥输入。沿用现有单体、认证、权限、PostgreSQL RLS、Audit/Outbox 与幂等机制。

## 决定

- 每组织一套启用配置，`ai.provider.manage` 管理；对话仍按组织与所有者隔离。接口兼容 OpenAI Chat Completions，服务名称、基础地址、模型由用户配置，支持云端和显式允许的本机/内网服务。
- 密钥不回显。使用高熵 `SESSION_SECRET` 与组织 UUID 经 HKDF 派生组织密钥，再以 Fernet 加密。数据库保存密文，审计仅保存版本/启用/是否更换密钥，不保存 URL、密钥或请求全文。
- 修改协议或服务源必须重新填写或清除密钥。版本冲突要求重新读取；所有配置变更使旧会话上下文失效，避免把旧资料送往另一个供应商。
- 公网只允许 HTTPS。本机/内网需要显式开启，DNS 解析结果整体检查后固定目标 IP，保留 Host/TLS SNI，拒绝重定向、metadata 和特殊地址。请求 identity 编码并拒绝压缩响应，在读取前保持响应长度边界。
- 连接测试使用固定文本且在数据库事务之外执行；返回后重新认证、检查权限与配置版本。真实问答另行验证，不把连接测试等同业务能力验收。
- 本地 embedding 保持独立，聊天服务配置不改变商品语义搜索。

## 后果与复核点

备份恢复必须安全保留 `SESSION_SECRET`；更换该值后需重新输入模型密钥。本期不新增密钥管理基础设施，也不实现浏览器读取密钥、供应商原生协议适配或自动故障转移。若需要多个模型、按用户计费或独立密钥轮换，另行明确范围。

允许内网访问意味着有此管理权限的用户可以选择组织可达的模型服务，权限不能下放给普通开单人员。后台只提供固定模型请求，AI 不获得任意 HTTP 工具。
