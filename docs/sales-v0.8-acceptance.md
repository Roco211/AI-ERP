## D 退货与冲销

- [ ] D01 退货仅原POSTED出库、原客户/仓库/单位；跨来源/租户/超量拒绝，关闭订单允许合法退货。
- [ ] D02 当前均价变化后，退货仍回收原出库实际成本；入库价值正确参与当前移动均价。
- [ ] D03 原价销售冲减与原实际成本回收分别记录；最后退完各自清零，部分舍入溢出明确报错。
- [ ] D04 并发退货不超过原实发；退货不恢复履约/占用，原成本为零也正确。
- [ ] D05 出库冲销恢复原库存/价值/均价及原占用；退货冲销恢复退货额度；原事实保留、重复冲销拒绝。
- [ ] D06 后续流水/有效退货依赖拒绝出库冲销；CLOSED出库冲销拒绝；不支持部分/级联冲销。
