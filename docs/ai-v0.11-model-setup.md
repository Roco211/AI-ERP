# 在网页设置模型服务

登录后打开 **设置 → 模型服务**（`/settings/llm`）。管理员需要 `ai.provider.manage` 权限；同一组织使用一套配置，其他组织独立。

1. 选择预设或“自定义”，填写服务名称、API 基础地址及模型名称。
2. 输入服务商提供的 API 密钥；支持不要求密钥的本地服务。页面不会重新显示已保存的密钥。
3. 云端地址使用 HTTPS。本机或局域网服务需要明确勾选允许内网访问；地址从 **ERP 后端所在电脑/服务器** 访问。
4. 启用并保存，再点击“测试连接”。测试只发送固定测试文本，不读取业务资料。
5. 连接成功后进入 **AI 助手**，新建对话。实际问答会向选定服务发送当前问题及所需的、当前账户有权读取的资料。

接口须兼容 OpenAI Chat Completions 的请求与响应格式。基础地址例如 `https://服务域名/v1`；粘贴完整的 `/chat/completions` 地址也会自动规范化。不支持仅有原生 Messages 等另一种协议的接口；没有静默切换供应商。

自然语言开单请在本轮完整给出商品、客户/供应商、仓库、单位、数量及手工单价（销售也可采用现有自动报价）。补条件时请将其与完整开单内容一起提交；本期不会自动把旧轮次的数量、价格或实体选择当作新的建单指令。已有预览可直接在表单里修改后重新计算。

切换地址或协议时必须重新输入或清除旧密钥。保存采用版本校验，其他管理员同时修改时需重新读取。模型设置或权限变化后，旧对话不再用于继续问答，应新建对话。

**查询与开单**：可以询问库存、经营概览、未结清往来或补货依据。请用准确商品/往来编码与单位减少歧义；数量与手工价格使用数字。销售/采购先展示预览，修改后重新预览，点击确认只创建草稿。确认订单、出入库和收付款仍在原业务页面操作。

每日简报直接使用系统统计，默认上一个完整业务日，不消耗模型调用。期间销售/现金与当前库存/往来余额分别列示。系统没有到期日，不能判断逾期。

本地商品 embedding 是独立配置；更改聊天模型不更改已有 Ollama/BGE-M3 商品搜索。

## 运维与恢复

- 密钥使用组织隔离的加密存储。`SESSION_SECRET` 是解密依赖，数据库备份须配套安全保存该服务端配置；更换后需在网页重新输入模型密钥。
- 聊天正文、提案正文与 checkpoint 保留七天；删除或到期不会删除业务单据和永久建单回执。现有 Celery 每分钟有界清理。
- 默认不上传 LangSmith trace。可选 `AI_TRACE_ENABLED`、`AI_TRACE_API_KEY`、`AI_TRACE_PROJECT` 仅启用运行元数据，提示/工具结果/密钥不上传。
- 模型故障不会关闭普通 ERP 查询或人工开单。页面显示请求标识与安全错误说明；重试沿原轮次执行，累计最多两次尝试、五次模型决策和八次工具查询。
